# Website Araffi

Website portofolio pribadi untuk memperkenalkan diri dan mendokumentasikan proses belajar pengembangan web.

## Halaman
- `index.html` — Beranda dan ringkasan portofolio.
- `about.html` — Tentang saya.
- `skills.html` — Materi dan keahlian yang sedang dipelajari.
- `projects.html` — Dokumentasi proyek/latihan.
- `biodata.html` — Formulir biodata.
- `contact.html` — Informasi kontak.

## File pendukung
- `style.css` — Tampilan, layout, responsif, dan foto background.
- `script.js` — Menu navigasi mobile dan notifikasi formulir.

## Menjalankan
Upload seluruh isi folder ini ke root repository GitHub Pages. Pastikan `index.html` berada langsung di root repository.

## Catatan formulir
Formulir biodata merupakan demonstrasi front-end. Data tidak disimpan ke database atau dikirim ke server.
